An Improved GradCAM Explainable AI model for Multi-label Chest X-ray Classification and Analysis.

A single Jupyter Notebook file contains the complete code.

A modified ResNet101 model with four classifiers, corresponding to the four class labels we utilized: Atelectasis, Effusion, Infiltration, and Normal, was trained on a subset of ChestX-ray8 dataset. https://nihcc.app.box.com/v/ChestXray-NIHCC

This repo is for the test dataset obtained from the OpenI chest x-ray dataset and the improved GradCAM. https://openi.nlm.nih.gov/faq?download=true

This improved GradCAM can generate a composite heatmap for multiple diseases (within a threshold) in a single image and also displays their class label names over their respective highlighted regions.
