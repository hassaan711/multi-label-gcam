An Improved GradCAM Explainable AI model for Multi-label Chest X-ray Classification and Analysis.
A single Jupyter Notebook file contains the complete code.
A modified ResNet101 model with multiple classifiers (in this case four, for the four class labels) was trained on a subset of ChestX-ray8 dataset.
This repo is for the test dataset obtained from the OpenI chest x-ray dataset and the improved GradCAM. 
This improved GradCAM can generate a composite heatmap for multiple diseases in a single image and also displays their class label names over their respective highlighted regions.
